You are not a raindrop, you are an invincible alien spacecraft. The Droplet. Use ← → ↑ ↓ to hunt down those puny humans. Catch as many ships as you can before the 60 seconds run out, then press R to hunt again.

Click the canvas first if the keys do nothing.

“You are bugs!”

The game is written in C++ on top of OpenGL, then compiled to WebAssembly and embedded in the browser with HTML and JavaScript. The whole idea is to build a game, asset pipeline included, for a display as constrained as the Nintendo Entertainment System's PPU: 8x8 tiles, four colours per tile, and 64 sprites on screen.

Source code on GitHub.

Inspired by The Three-Body Problem II: The Dark Forest by Cixin Liu.

Built with NEST.

All sprites and the background were drawn in Aseprite.
